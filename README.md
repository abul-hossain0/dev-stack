# 🚀 Dev Stack

A modern and responsive Development Stack Builder built with React, TypeScript, and Tailwind CSS.

## ✨ Features

- Responsive Navbar and Hero Section
- Technology cards with category, rating, difficulty, and badge
- Add technologies to Your Stack
- Remove individual technologies or Remove All
- Duplicate technology prevention
- React Toastify notifications
- Loading state for JSON data
- Responsive design for mobile, tablet, and desktop

## 🛠️ Technologies

- React
- TypeScript
- Tailwind CSS
- React Toastify
- JSON
